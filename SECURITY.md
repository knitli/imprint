# Security policy

## Reporting a problem

**Do not open a public issue for a security problem.**

Report it privately through [knitli.com/security](https://knitli.com/security/). Include:

- what the problem is and what someone could do with it;
- how to reproduce it, using **invented data only**;
- the commit or version you tested.

We will acknowledge your report, keep you informed, and credit you if you wish once a fix is available.

## What is in scope

Imprint has no released application yet. Reports about the spikes, the CI configuration or the dependencies we pin are still welcome.

Problems in the OpenSCG format, schema or reference library should go to the [OpenSCG project](https://github.com/knitli/OpenSCG), which has its own disclosure route.

## Never send us sensitive material

Do not send real, controlled or classified information, even to show a problem. If a problem only appears with real data, describe it in general terms and we will work out a synthetic reproduction with you.
